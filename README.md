
# EstoqueFácil

Sistema web para controle de estoque e gestão comercial voltado a micro, pequenos e médios empreendedores — como lojistas, mercadinhos, lojas de roupas, papelarias e comércios em geral.

Substitui o controle manual por planilhas e cadernos por uma plataforma centralizada, com alertas automáticos, geração de receita integrada às vendas e sugestão inteligente de reposição de produtos.

## Funcionalidades principais

- Cadastro e categorização de produtos
- Registro de entradas e saídas de estoque
- Geração automática de receita a partir das vendas
- Alertas de estoque baixo ou esgotado
- Histórico completo de movimentações
- Dashboard com indicadores de desempenho
- Sugestão de reposição com base no histórico de vendas
- Controle de usuários e permissões (administrador e funcionário)
